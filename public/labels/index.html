Labels

How it works

The one list of labels, like Season: Fall, that every recipe picks from.

Keeping one list means nobody ends up with Fall and Autumn. Each key, like Season, is also a category on the Recipe board. Renaming a label renames it on every recipe; removing one takes it off them all.

Typing a key that's already on the list adds the values under it. You can also type it all in the key box, like Season: Fall, Winter. Give a value keywords (+ keywords, like pumpkin, squash for Fall) and Recipe box's Suggest labels offers it for recipes that mention them.
